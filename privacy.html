Privacy Policy – rclone server

Effective date: 6 November 2026

About the application

rclone server is a private, single-user application operated by Maksim Manojlović. It uses rclone on a personal home server to store backup archives in the owner's own Google Drive. It is not offered to the public.

Data accessed

The application requests only the Google Drive drive.file scope. It can access only files and folders that the application itself has created (backup archives). It does not access any other files, contacts, email or other Google account data.

How data is used

Data is used solely to upload, list, download and delete the owner's own backup archives. The application does not sell, share or transfer Google user data to any third party, does not use it for advertising, and does not use it to develop, improve or train artificial intelligence or machine learning models.

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

The OAuth access token is stored only on the owner's private server, in a configuration file readable only by the owner's user account. The server is not publicly accessible.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
