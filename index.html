rclone server

rclone server is a private, single-user application operated by Maksim Manojlović. It runs rclone on a personal home server and uploads backup archives of that server to the owner's own Google Drive.

The application requests only the drive.file scope, which gives it access exclusively to files that the application itself has created. It cannot see or read any other files in Google Drive.

This application is not offered to the public and is used only by its owner.
